      What are we selling?
      
            
      
              An evidence service for agents. Give it a task, maintain the
              observations that matter, and wake the agent when the decision
              changes—with a receipt explaining why.
            
      
            
      
              
      
                
      The first product
      
                
      
                  A developer API for reliable waits on payments, releases and
                  other external work. The task determines the observation plan;
                  events update the decision.
                
      
              
      
              
      
                
      Working here
      
                
      
                  Doc-grounded compilation, typed guards, complete pagination,
                  persistent watches, evidence expiry and a durable queue.
                  GitHub public reads are live when selected; the other examples
                  are simulated.
                
      
              
      
              
      
                
      Still to build
      
                
      
                  Authenticated provider connectors, verified webhooks,
                  scheduled reconciliation, tenant isolation and distributed
                  delivery. Customer demand and pricing remain hypotheses.
