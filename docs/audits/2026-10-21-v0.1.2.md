# v0.1.2 qualification — 2026-10-21

This release packages the local agent handoff and its one-click workbench timeline.
The UI uses a clearly labeled reference agent; its process, CSV, watch, saved
completion, continuation and verified answer are real. The optional CLI model
adapter resumes an exact saved Codex session. No runtime dependency was added.

Release checks cover 385 unit/API tests, 41 known simulated regression scenarios,
Python 3.11/3.15 CI, lint/format, JavaScript syntax, reproducible archive bytes and
manifest verification. The exact extracted archive is exercised in Linux/Python
3.15, including UI handoff and upgrade/startup rollback/interrupted-commit recovery.
The archive includes pinned source seeds, Apache-2.0 licensing, upstream notices,
the README screenshot, and the demo modules. Private databases, run folders,
credentials and model logs are excluded.

The [UI audit](2026-10-21-agent-demo-ui.md) records actual desktop/mobile stopped
and completed states, reload recovery, token/origin checks and retention. Its
separate design review returned ship for the scoped extension. The original
[handoff audit](2026-10-21-agent-handoff.md) distinguishes real model evidence from
mock CLI contract tests and documents the local acknowledgement recovery boundary.

macOS remains the supported host. Stored database/plan/receipt formats and the
immutable launcher contract are unchanged. Existing installs use their ordinary
update path; consent, watches, consumers and prior evidence must be retained.
Publication and the live user's backed-up upgrade are verified separately in
private compressed operator receipts, without rewriting the release archive.

These finite implementation-authored tests establish this controlled behavior,
not an independent semantic benchmark, producer attestation, exactly-once external
actions or a production reliability guarantee.
